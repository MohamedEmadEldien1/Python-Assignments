# 🐍 Python Assignments & Problem Solving Portfolio

Welcome to my Python learning repository! This project contains a collection of practical assignments, exercises, and problem-solving notebooks covering foundational to intermediate Python concepts.

---

## 📁 Contents & Structure

* **`solution assignment 2.ipynb`**: Covers basic variable initialization, arithmetic operations, user input handling (`input()`), and simple math calculations.
* **`solution assignment 3.ipynb`**: Focuses on string manipulation, slicing, string methods, and conditional checks (`if-elif-else`).
* **`solution assignment 4.1.ipynb` & `solution assignment 4.2.ipynb`**: Advanced foundational exercises covering basic arithmetic, string indexing, formatting, built-in functions, and `if` conditions.
* **`solution Assignment 5 python.ipynb`**: Deep dive into **Lists** and **For Loops**.
* **`solution Assignment 7.1 python.ipynb` & `solution Assignment 7.2 python.ipynb`**: Functions practice exercises structured by difficulty levels, covering custom functions, return statements, and algorithm logic.
